# 智能会议纪要系统 — UI 交互设计

## 1. 设计原则

- **极简操作**：核心流程（开始录音 → 停止 → 查看纪要）最多 2 步点击
- **状态可见**：录音状态、ASR 连接状态、LLM 生成状态始终可见
- **容错设计**：设备断开、连接失败等异常有明确提示和恢复路径
- **响应式**：适配 1280px+ 桌面端，最小支持 1024px

## 2. 色彩与样式

### 2.1 主题色

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | `#2563EB` (blue-600) | 按钮、链接、焦点态 |
| 成功 | `#16A34A` (green-600) | 录音中、连接成功 |
| 警告 | `#EA580C` (orange-600) | 连接断开、重连中 |
| 错误 | `#DC2626` (red-600) | 录音失败、API 错误 |
| 背景 | `#F8FAFC` (slate-50) | 页面底色 |
| 卡片 | `#FFFFFF` | 卡片/面板背景 |

### 2.2 录音动画

录音中状态使用脉冲动画：

```
┌─────────┐
│ ● 录音中 │  红色圆点 + 文字，圆点带 CSS pulse 动画
└─────────┘
```

CSS 实现：
```css
@keyframes pulse-ring {
  0% { transform: scale(0.8); opacity: 1; }
  100% { transform: scale(1.4); opacity: 0; }
}
.recording-dot {
  width: 12px; height: 12px;
  border-radius: 50%;
  background: #DC2626;
  position: relative;
}
.recording-dot::after {
  content: '';
  position: absolute;
  inset: -4px;
  border-radius: 50%;
  border: 2px solid #DC2626;
  animation: pulse-ring 1.5s ease-out infinite;
}
```

### 4.2 FunASR 配置卡片

**字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| 端点地址 | Input | WebSocket 地址，placeholder: `ws://host:port/ws` |
| 连接状态 | Badge | 已连接(绿) / 未连接(灰) / 连接失败(红) |
| 测试连接 | Button | 点击后尝试 WebSocket 握手，显示结果 |

**测试连接交互：**

```
点击"测试连接"
  → 按钮变为 "测试中..." (loading)
  → 建立 WebSocket 连接
  → 成功：状态变为 "● 已连接"，显示 "连接成功" toast
  → 失败：状态变为 "● 连接失败"，显示错误信息 toast
```

### 4.3 LLM 配置卡片

**字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| API 地址 | Input | OpenAI 兼容端点，placeholder: `http://host:port/v1` |
| API Key | Password | 密码输入框，显示/隐藏切换 |
| 模型名称 | Input | 默认: `qwen3.6-35b` |
| 测试 API | Button | 发送测试请求 |

**测试 API 交互：**

```
点击"测试 API"
  → 按钮变为 "测试中..."
  → 发送: POST {api_url}/chat/completions
         Body: { model, messages: [{role:"user", content:"你好"}] }
  → 成功：显示 "API 连接正常" toast
  → 失败：显示具体错误信息（401 认证失败、404 端点不存在等）
```

### 4.4 系统提示词配置

**字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| 提示词内容 | Textarea | 多行文本，最小 6 行高度，支持换行 |
| 保存 | Button | 保存到数据库 |
| 重置为默认 | Button | 恢复默认提示词（需二次确认） |

**默认提示词：**

```
你是一个专业的会议纪要助手。请根据以下会议转写记录，生成结构化的会议纪要。

要求：
1. 识别并标注会议主题
2. 按发言人分段，提炼各自要点
3. 总结会议关键结论
4. 列出待办事项（如有），标注负责人
5. 使用清晰的 Markdown 格式输出

会议转写记录：
{transcript}
```

### 4.5 声纹管理

| 列 | 说明 |

## 8. 快捷键
